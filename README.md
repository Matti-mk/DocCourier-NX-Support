# DocCourier NX – Support & Feedback

**Offizieller Support für DocCourier NX / Official support for DocCourier NX**

Dieses öffentliche Repository dient ausschließlich der Meldung von Fehlern, Verbesserungsvorschlägen und Fragen. Der Quellcode von DocCourier NX wird hier nicht veröffentlicht.

This public repository is for bug reports, feature requests, and questions only. The DocCourier NX source code is not published here.

## 🇩🇪 Deutsch

- 🐛 [Fehler melden](https://github.com/Matti-mk/DocCourier-NX-Support/issues/new?template=01-fehler.yml)
- 💡 [Verbesserung oder neue Funktion vorschlagen](https://github.com/Matti-mk/DocCourier-NX-Support/issues/new?template=02-vorschlag.yml)
- 📋 [Bekannte Meldungen ansehen](https://github.com/Matti-mk/DocCourier-NX-Support/issues)
- ❓ [Fragen und Diskussionen](https://github.com/Matti-mk/DocCourier-NX-Support/discussions)

Bitte gib bei Fehlermeldungen die DocCourier-NX-Version, deinen Browser und die Schritte an, mit denen sich der Fehler nachvollziehen lässt.

**Datenschutz:** Teile keine Passwörter, API-Schlüssel, Dokumentinhalte oder personenbezogene Daten. GitHub-Issues sind öffentlich einsehbar. Lade Screenshots nur hoch, wenn vertrauliche Inhalte geschwärzt sind.

## 🇬🇧 English

- 🐛 [Report a bug](https://github.com/Matti-mk/DocCourier-NX-Support/issues/new?template=01-fehler.yml)
- 💡 [Request an improvement or feature](https://github.com/Matti-mk/DocCourier-NX-Support/issues/new?template=02-vorschlag.yml)
- 📋 [View existing reports](https://github.com/Matti-mk/DocCourier-NX-Support/issues)
- ❓ [Questions and discussions](https://github.com/Matti-mk/DocCourier-NX-Support/discussions)

For bug reports, please provide your DocCourier NX version, browser, and reproducible steps.

**Privacy:** Do not post passwords, API keys, document contents, or personal information. GitHub issues are public. Redact sensitive details from screenshots before uploading them.
